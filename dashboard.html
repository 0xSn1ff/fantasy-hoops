How this is calculated
  • Value (FP/G) blends season and recent fantasy-points-per-game: value = w·L7 + (1−w)·season, where w is the recent-form weight slider (default 40%).
  • Trend is last-7-days FP/G minus season FP/G — green means heating up, red means cooling off.
  • Games is how many times the player's NBA team plays this fantasy week. In a points league more games = more counting stats.
  • Upgrades over finds your weakest rostered player who shares a position and shows the value you'd gain.
  • Agree? cross-references my value ranking with LineupExperts' Free Agent Finder — the basketball version of your Savant-vs-LE check. ● Both both like them, ● You only my model, ● LE only LineupExperts.
  • LE tag is LineupExperts' Buy-Low / Sell-High signal; drop on your roster is their Drop Advisor.
